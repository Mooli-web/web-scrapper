# سامانه اختصاصی هوش، پایش و مانیتورینگ قیمت دیجی‌کالا (Digikala Intelligence)
> **پروژه اول پلتفرم جامع تحلیل بازار دیجیتال ایران (Cloud-Native Digikala Monitor)**

این سامانه یک راهکار کاملاً مستقل، امن و ۲۴ ساعته برای پایش عمیق و پیوسته کالاهای نو در **دیجی‌کالا (digikala.com)** با اتصال مستقیم به پایگاه داده ابری **CockroachDB Serverless** است.

---

## 🌟 قابلیت‌های برجسته موتور دیجی‌کالا

1. **الگوریتم کشف تخفیف‌های فیک (Fake Discount Detector):**
   - محاسبه ریاضی و دقیق تخفیف واقعی بر اساس تاریخچه قیمت، نه اعداد نمایشی و کاذب.
2. **رهگیری جنگ قیمت فروشندگان و بای‌باکس (Buy Box & Seller War Tracker):**
   - مانیتورینگ مداوم فروشنده برنده جعبه خرید (Buy Box)، تنوع فروشندگان و تغییرات قیمت لحظه‌ای.
3. **دفتر کل کالاها و رویدادها با مرتب‌سازی چندستونه (Multi-Column Sorting):**
   - مرتب‌سازی تعاملی بر اساس قیمت فروش، درصد افت قیمت، سطح بحرانی بودن و تاریخ بروزرسانی.
4. **سیستم خزش پیوسته ۲۴/۷ (Polite In-Memory Delta Crawler):**
   - مدیریت کش در حافظه برای به حداقل رساندن مصرف Request Units در CockroachDB.
5. **داده‌های ۱۰۰٪ واقعی (Zero Synthetic Data):**
   - عدم استفاده از دیتای فیک؛ در صورت خالی بودن دیتابیس، حالت شفاف Cold-Start نمایش داده می‌شود.

## 🏗️ ساختار پروژه

```text
1_digikala_cloud/
├── crawler/
│   ├── adapters/digikala.py  # آداپتور رسمی و دقیق خزش دیجی‌کالا
│   ├── engine.py             # ورکر خزش پیوسته ۲۴ ساعته دیجی‌کالا
│   ├── db.py                 # کانکشن پول CockroachDB با پاکسازی خودکار DSN
│   └── config.py             # تنظیمات و نرخ تاخیر خزش
├── server/
│   ├── app.py                # سرور FastAPI و سرو استاتیک React
│   ├── routes.py             # API تخفیف فیک، جنگ قیمت، دفتر کل و تله‌متری
│   └── auth.py               # احراز هویت ادمین
├── database/
│   ├── schema.sql            # ساختار دیتابیس مستقل دیجی‌کالا
│   └── seed_data.sql         # دسته‌بندی‌های پیش‌فرض
├── dashboard/                # فرانت‌اند اختصاصی React + Tailwind CSS
├── render.yaml               # تنظیمات استقرار خودکار روی Render
└── requirements.txt          # پکیج‌های پایتون
```

## 🚀 راهنمای نصب و راه‌اندازی روی Render

1. در پنل [render.com](https://render.com) یک **Web Service** بسازید.
2. در بخش Environment Variables متغیر `DATABASE_URL` را با رشته اتصال CockroachDB مقداردهی کنید.
3. متغیر `AUTO_START_CRAWLER` را برابر `true` قرار دهید تا به محض استقرار، خزش آغاز شود.
