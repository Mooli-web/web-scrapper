# سامانه اختصاصی هوش، پایش و مانیتورینگ مزایدات ایسام (Esam Intelligence)
> **ماژول چهارم پلتفرم ۴ بازاری قیمت دیجیتال ایران (Quad-Market Platform)**

این پروژه یک سیستم کاملاً مستقل، ایزوله و اختصاصی برای پایش ۲۴ ساعته بازار **ایسام (esam.ir)** است. ایسام به عنوان مرجع اصلی مزایدات اینترنتی و خرید/فروش امن کالاهای نو، در حد نو، استوک و دست‌دوم در ایران شناخته می‌شود.

---

## 🌟 قابلیت‌های برجسته موتور ایسام

1. **پایش دوگانه (Dual-Mode Watcher):**
   - **دیده‌بان مزایدات داغ و رو به اتمام (Auctions Ending Soon):** استخراج لحظه‌ای بالاترین قیمت پیشنهادی (`Highest Bid`)، قیمت پایه، تعداد پیشنهادات و شمارش معکوس زمان باقی‌مانده.
   - **پایش کالاهای قیمت ثابت و استوک:** خزش شاخه‌های هدف لپ‌تاپ، کارت گرافیک، پردازنده، قطعات، کنسول‌های بازی و موبایل‌های عتیقه.
2. **درجه‌بندی استاندارد وضعیت سلامت (Condition Normalizer):**
   - تفکیک خودکار به ۵ رده: `نو (پلمپ/آکبند)`، `در حد نو`، `استوک گرید A`، `دست دوم`، `معیوب / جهت قطعات`.
3. **دفتر کل تعاملی با مرتب‌سازی چندستونه (Multi-Column Sorting):**
   - جستجوی سریع، فیلتر ترکیبی دسته‌بندی و وضعیت، مرتب‌سازی بر اساس قیمت، زمان، پیشنهادات و فروشنده.
4. **ثبت رویدادهای بازار (Price & Bid Events Ledger):**
   - کشف و ثبت کاهش قیمت‌های لحظه‌ای و افزایش پیشنهادات در مزایدات با نشان‌گذاری فرصت‌های طلایی (`GOLDEN`).
5. **اتصال مستقیم به CockroachDB Serverless:**
   - مایگریشن و ایجاد خودکار ساختار جداول بدون وابستگی به سایر دیتابیس‌ها.
6. **داده‌های ۱۰۰٪ واقعی (Zero Synthetic Data):**
   - تمام اطلاعات مستقیماً از وب‌سایت ایسام استخراج شده و در صورت خالی بودن دیتابیس، حالت شروع اولیه (Cold Start) شفاف نمایش داده می‌شود.

## 🏗️ ساختار پروژه

```text
4_esam_cloud/
├── crawler/
│   ├── esam_adapter.py      # اسکرپر پیشرفته HTML و JSON-LD ایسام
│   ├── engine.py            # ورکر خزش پیوسته ۲۴ ساعته با کش حافظه
│   ├── db.py                # مدیریت کانکشن CockroachDB و Sanitize DSN
│   └── config.py            # لود تنظیمات از .env
├── server/
│   ├── app.py               # سرور اصلی FastAPI و سرو فایل‌های فرانت‌اند
│   ├── routes.py            # مسیرهای REST API (اقلام، مزایدات، رویدادها، تله‌متری)
│   └── auth.py              # احراز هویت سبک
├── database/
│   ├── schema.sql           # ساختار جداول دیتابیس ایسام
│   └── seed_data.sql        # دسته‌بندی‌های پیش‌فرض
├── dashboard/               # داشبورد کامل React + Vite + Tailwind CSS
├── run_windows.bat          # رانر تک‌کلیک ویندوز
├── run_local.py             # لانچر پایتون
├── render.yaml              # کانفیگ دیپلوی رایگان روی Render
└── requirements.txt         # پکیج‌های سبک پایتون
```

## 🚀 راهنمای نصب و راه‌اندازی

### ۱. اجرای ابری روی Render
1. ریپازیتوری را روی GitHub پوش کنید.
2. در داشبورد Render یک **Web Service** از نوع `render.yaml` بسازید.
3. در تب Environment، متغیر `DATABASE_URL` را با استرینگ اتصال دیتابیس CockroachDB مقداردهی کنید.

### ۲. اجرای محلی روی کامپیوتر (ویندوز / لینوکس / مک)
```bash
# نصب وابستگی‌ها
pip install -r requirements.txt

# اجرای سرور و باز شدن خودکار مرورگر روی http://localhost:8000
python run_local.py
```
یا در ویندوز کافیست فایل `run_windows.bat` را اجرا نمایید.
