# هاب مرکزی پایش و آربیتراژ ۴ بازاری (Quad-Market Intelligence Master Hub)
> **موتور تجمیع مشترک، تطبیق هوشمند کالاها و استخراج فرصت‌های آربیتراژ (دیجی‌کالا، ترب، دیوار و ایسام)**

این سامانه قلب تپنده و مغز متفکر پلتفرم است که خروجی هر ۴ موتور مستقل را روی یک **پایگاه داده مشترک لوکال (بدون محدودیت حجم و هزینه)** گردآوری کرده و ارزش‌های تجاری زیر را خلق می‌کند:

---

## 🌟 قابلیت‌های کلیدی هاب مرکزی

1. **دیتابیس مشترک لوکال پرسرعت (Zero-Latency Local Master DB):**
   - استفاده از معماری دیتابیس لوکال پرسرعت با حالت WAL (Write-Ahead Logging) بدون محدودیت فضا یا هزینه دلاری ابری.
2. **موتور تطبیق هوشمند کالاها (Entity Matcher & Fuzzy Resolver):**
   - پاکسازی اسامی، استخراج مشخصات سخت‌افزاری (رم، حافظه، مدل گرافیک، نسخه کنسول) و اختصاص یک `canonical_key` استاندارد برای هر محصول در هر ۴ بازار.
3. **شکارچی فرصت‌های طلایی آربیتراژ (Arbitrage & Golden Flip Finder):**
   - مقایسه بلادرنگ قیمت‌های دست‌دوم/استوک دیوار و ایسام با کف قیمت نوی بازار آزاد در ترب و دیجی‌کالا.
   - رده‌بندی معاملات سودآور به سه دسته: `GOLDEN_FLIP` (تخفیف > ۳۰٪)، `SUPER_DEAL` (۲۰٪ تا ۳۰٪) و `UNDERVALUED` (۱۰٪ تا ۲۰٪).
4. **شاخص استهلاک و حباب برندها (Brand Depreciation Curves):**
   - تحلیل ریاضی نسبت افت ارزش برندهای اپل، سامسونگ، سونی، ایسوس و لنوو در بازار مصرف‌کننده.
5. **پایپ‌لاین پالایش داده و خروجی هوش مصنوعی (Purification & ML-Ready Exporter):**
   - پالایش چندلایه: لیست سیاه کلیدواژه‌ای (Regex Blacklist)، کف قیمت معقول هر دسته، و انحراف قیمت از مرجع بازار؛ اقلام مشکوک برای بازبینی به ایجنت Arena ارسال می‌شوند (`exports/audit_review_for_agent.json`).
   - تولید خودکار دیتاست‌های تمیز و استاندارد عددی در قالب `CSV` و `JSON` برای آموزش مدل‌های پیش‌بینی قیمت و یادگیری ماشین.

## 🚀 راهنمای نصب و راه‌اندازی گام‌به‌گام

### روش اول: اجرای تک‌کلیک روی ویندوز
کافیست روی فایل **`run_windows.bat`** دابل‌کلیک کنید. این اسکریپت خودکار کارهای زیر را انجام می‌دهد:
1. ساخت محیط مجازی `venv` (در صورت نبود).
2. نصب پیش‌نیازها از `requirements.txt`.
3. راه‌اندازی سرور محلی روی پورت ۷۰۰۰ و باز کردن خودکار داشبورد در مرورگر روی آدرس `http://localhost:7000`.

### روش دوم: اجرای دستی در خط فرمان (ویندوز / لینوکس / مک)
```bash
cd 5_unified_local_hub

# ۱. نصب پکیج‌ها
pip install -r requirements.txt

# ۲. اجرای سرور
python run_local.py
```
سپس مرورگر را باز کرده و به آدرس `http://localhost:7000` بروید.
